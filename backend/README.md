# Backend – AI-Powered RFP Management System

This is the backend service for the AI-Powered RFP Management System.
It is built using **Node.js, Express, TypeScript, and MongoDB**.

---

## 🚀 Tech Stack

- Node.js
- Express
- TypeScript
- MongoDB (Mongoose)
- Nodemon (development)

---

## 📦 Prerequisites

- Node.js (v18+ recommended)
- MongoDB Atlas (free tier) or local MongoDB
- npm

---

## ⚙️ Environment Setup

1. Create a `.env` file in the `backend` directory
2. Copy contents from `.env.example`
3. Fill in required values:

```env
PORT=4000
MONGODB_URI=your_mongodb_connection_string
